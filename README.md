# Bit by Bit

> 작은 단위의 선택과 고민이 모여 하나의 결과를 만든다.

프론트엔드 개발자 **junijaei**의 개인 기술 블로그입니다. 모던 웹 디자인 위에 레트로 픽셀 감성을 얹은 "레트로-모던 퓨전" 스타일을 추구합니다.

---

## 소개

프론트엔드를 설계하고 구현하며 쌓아온 생각과 경험을 기록하는 공간입니다. 단순한 기술 메모를 넘어, 왜 이런 선택을 했는지, 어떤 고민을 거쳤는지를 함께 담습니다.

## 디자인 철학

픽셀 도트 요소는 **포인트 장식** 역할(시각 비중 15~20%)에 그치고, 모던 디자인 원칙이 **핵심 기반**(80~85%)을 이룹니다. 장식보다 가독성을, 화려함보다 미니멀을 우선합니다.

## 기술 스택

| 분류 | 기술 |
|------|------|
| 프레임워크 | Next.js 16 (App Router) |
| 언어 | TypeScript (strict mode) |
| 스타일 | Tailwind CSS v4 |
| CMS | Notion API |
| 배포 | Vercel |
| 테마 | next-themes (다크/라이트 모드) |

**폰트:** Pretendard (본문) · D2Coding (코드) · Silkscreen / Galmuri (픽셀 액센트) · Geist Mono

## 주요 특징

- **Notion을 CMS로** — Notion 블록을 Markdown으로 변환하지 않고, 블록 타입별 React 컴포넌트로 직접 렌더링하여 구조와 디자인 제어권을 유지합니다.
- **ISR** — 콘텐츠를 1시간 주기로 정적 재생성하여 빌드 없이 글이 반영됩니다.
- **사이드바 카테고리** — Notion 데이터베이스 구조를 그대로 반영한 계층형 카테고리 네비게이션을 제공합니다.
- **페이지뷰 · 스크롤 깊이 추적** — 방문자 행동 데이터를 수집해 콘텐츠 품질을 개선합니다.
