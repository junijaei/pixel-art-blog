# Hero visual

히어로의 기존 점 우주 배경, 궤도, 정팔면체 오브제를 제거하고 React Bits PixelSnow를 배경으로 적용했다. 제목·소개·CTA의 HTML과 기존 페이지 레이아웃은 유지한다. PixelSnow는 독립된 WebGL2 캔버스에서 실행하고, 소스는 React Bits registry에서 가져와 프로젝트 안에 둔다. 설치한 런타임 의존성은 없다.

## 적용 설정

사용자 제공 URL의 `drift` preset을 기준으로 `density=0.6`, `variant=square`, `accumulate=true`를 적용한다. 공중 눈송이는 원래 픽셀 실루엣을 유지하되 모든 픽셀의 명도를 같게 해 무늬를 제거한다. preset은 낙하 속도 1, 바람 0.25, 흔들림 0.5, 크기 1, 픽셀 간격 3, 깊이 0.6, 글로우 0.8, 반짝임 0.35다. 라이트 모드는 짙은 회색 눈을, 다크 모드는 옅은 회색 눈을 쓴다. 공중 눈송이는 전체 밝기의 55%로 렌더링하고, 바닥에 쌓이는 눈은 원래 농도를 유지한다. 시스템이 동작 축소를 요청하면 눈은 낮은 속도로 계속 움직이고 바람·흔들림·반짝임·커서 반응을 줄인다.

PixelSnow 자체가 Canvas 렌더링, GPU 눈송이 버퍼, accumulation map, 글로우를 위한 WebGL 패스를 사용한다. WebGL2 생성이나 셰이더 링크가 실패하면 같은 사각 눈 효과를 Canvas 2D로 그려 빈 캔버스를 피한다. 시스템이 동작 축소를 요청하면 눈은 느리게 계속 움직이고 나머지 동작을 줄인다. 이 설정은 시각 디자인을 우선해 적용했으며, 이전 직접 작성 배경 렌더러보다 빠르다고 가정하지 않는다. 변경 후의 번들·프레임 성능 수치는 아직 따로 측정하지 않았다.

초기 WebGL 최적화(커밋 `4d90f9b`) 당시 홈 클라이언트 JavaScript 전송량은 측정 조건에서 498,710 bytes에서 251,420 bytes로 줄었다. 그 수치는 현재 PixelSnow 적용본의 번들 크기를 나타내지 않는다.
